# AI Engineering Workbench 0.1.0

`0.1.0` is the first local-first MVP release.

## Included

- Project registration with `harness.yaml` validation.
- Structured task import, deterministic backlog selection, and task state
  transitions.
- Git branch and isolated worktree creation.
- Provider-independent local agent sessions for manual, Codex CLI, and Claude
  Code.
- Configured validation command execution with persisted raw evidence metadata.
- Acceptance matrix tracking and manual evidence recording.
- Deterministic changed-file risk classification and review finding persistence.
- GitHub CLI pull-request preparation and confirmation-gated creation.
- Localhost API and operational dashboard.
- Sanitized portfolio metrics JSON export.
- End-to-end smoke workflow and MVP traceability matrix.

## Validation

The release-readiness baseline is:

```text
make check
56 backend tests passed
dashboard test/build passed
ruff, mypy, and bandit passed
```

The end-to-end workflow is covered by
`tests/integration/test_e2e_smoke.py::test_end_to_end_fixture_workflow`.

## Known Limits

- Live GitHub PR creation is not exercised in automated tests; tests use fake
  local `gh` and `git` tools.
- Dashboard interaction coverage is currently limited to API state and server
  rendering tests.
- Portfolio `tests_added` is task-type based rather than diff-count based.
- This release does not automatically merge pull requests.
